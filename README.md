## Описание проекта

Однопользовательская аркадная игра по мотивам **Agar.io**, реализованная с использованием объектно-ориентированного подхода на языке Python с применением библиотеки `pygame`. Игрок управляет клеткой на арене, поглощает питательные гранулы, увеличивая свой размер.

## Основные механики и особенности

- **Движение за курсором:** клетка игрока плавно следует за указателем мыши с учётом размера клетки.
- **Рост по площади:** при поглощении гранул площадь клетки увеличивается ($S = \pi r^2$), а радиус пересчитывается по формуле $r = \sqrt{S / \pi}$.
- **Поддержание баланса арены:** при съедании гранул на поле автоматически появляются новые объекты.
- **Счетчик:** в игре реализован счетчик, котрой показывает количество очков, набранных игроком.

## Установка и запуск

1. Создайте и активируйте виртуальное окружение:
   ```bash
   python3 -m venv venv
   source venv/bin/activate


2. Клонирование репозитория
   ```bash
   git clone https://github.com/akortee/agar_io.git
   cd agar_io

   ```

3. Создание и активация виртуального окружения

   **macOS / Linux:**

   ```bash
   python3 -m venv venv
   source venv/bin/activate

   ```

   **Windows:**

   ```bash
   python -m venv venv
   venv\Scripts\activate

   ```

4. Установка зависимостей

   ```bash
   pip install -r requirements.txt

   ```

5. Запуск программы

   ```bash
   python main.py

   ```
